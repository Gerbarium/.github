# Как поучаствовать в разработке

Спасибо, что хочешь помочь Gerbarium! 💚

## Быстрый старт

1. Форкни репозиторий
2. Создай ветку: `git checkout -b feature/моя-фича`
3. Установи зависимости: `npm install`
4. Запусти в dev-режиме: `npm run dev`
5. Внеси изменения, проверь: `npm run lint` и `npm run build`
6. Запушь и открой Pull Request

## Правила

- **Один PR — одна задача.** Не смешивай рефакторинг и новые функции
- Коммиты на русском или английском, коротко и по делу: `fix: вылет при входе в аккаунт`
- Перед PR убедись, что проходят `npm run lint` и сборка
- Большие изменения сначала обсуди в issue — возможно, это уже в работе

## Нашли баг, но не хочешь чинить сам?

Просто создай [баг-репорт](https://github.com/Gerbarium/gerbarium-launcher/issues/new/choose) — это тоже вклад!
